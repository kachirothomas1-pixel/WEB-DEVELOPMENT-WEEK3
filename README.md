# SpendWise - Budget Tracker (Visual Identity & CSS Styling)

A polished, modern web application designed to help users track personal expenses. This project enhances foundational HTML structures by implementing a professional visual identity using modern CSS.

## 🚀 Features & Enhancements
- **Cohesive Color Palette:** Utilizes a professional indigo and slate color scheme configured via CSS custom properties (`:root` variables) for consistent branding.
- **Custom Typography:** Integrated Google Fonts (`Poppins` for distinct, bold headers and `Inter` for clean, highly legible body text and form inputs).
- **Modern Box Model Layout ("Cards"):** Grouped core application sections—the header banner, the Add Expense form, and the expense log table—into distinct, padded, rounded containers with subtle drop shadows.
- **Interactive Tables & Forms:** Enhanced forms with custom focus states, padded table cells, distinct header styling with rounded corners, and alternating row colors (`nth-child(even)`) for improved data readability.
